LADE

安裝 LADE Aquarium

搶先體驗版還沒經過 Apple 公證，所以第一次打開時 macOS 會請你確認。大概一分鐘，而且只要做一次。

為什麼會有警告？公證需要 Apple 開發者會員——那是 LADE 的第一個里程碑。完成之後就不需要這一頁了。

macOS 15 Sequoia 以上

  1. 把 LADE Aquarium 放進「應用程式」

    解壓縮下載的檔案，把 LADE Aquarium 拖進「應用程式」檔案夾。

  2. 先打開一次

    macOS 會說無法驗證開發者。按 完成——不要按「丟到垃圾桶」。

  3. 在系統設定裡允許

    打開 系統設定 → 隱私權與安全性，往下捲到「安全性」，按 LADE Aquarium 旁邊的 強制打開，再用密碼或 Touch ID 確認。

  4. 再打開一次 LADE Aquarium

    在接著出現的對話框按 打開。之後就會正常打開。

macOS 13 Ventura 或 14 Sonoma

在「應用程式」裡按住 Control 點 LADE Aquarium，選 打開，在對話框裡再按一次 打開。上面系統設定的方法也可以用。

LADE Aquarium 可能會要求的權限

  • 行事曆 — 為了在桌面上顯示你的下一個行程。只在你的 Mac 上讀取。
  • 螢幕與系統錄音 — 讓音樂環與她的歌聲能跟著你播放的聲音。只即時分析——不錄、不存、不傳。
  • 輔助使用 — 只有在你打開「取代系統的音量提示」時才會問，用來接收音量、靜音與亮度鍵。

都是選用的；不給權限 LADE Aquarium 也能用。

移除

結束 LADE Aquarium，把它丟到垃圾桶，再刪掉 ~/Library/Application Support/Aquarium 這個檔案夾就能清掉設定。
