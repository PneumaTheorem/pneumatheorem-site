LADE Aquarium のインストール

早期アクセス版はまだ Apple の公証を受けていないため、最初の起動時に macOS が確認を求めます。一分ほどで終わり、一度だけで済みます。

なぜ警告が出るの？ 公証には Apple Developer の会員登録が必要で、それが LADE の最初のマイルストーンです。公証が済めば、このページは必要なくなります。

macOS 15 Sequoia 以降

  1. LADE Aquarium を「アプリケーション」へ

    ダウンロードしたファイルを解凍し、LADE Aquarium を「アプリケーション」フォルダへドラッグします。

  2. 一度開く

    「開発元を確認できません」と表示されます。完了 をクリックしてください（「ゴミ箱に入れる」ではなく）。

  3. システム設定で許可する

    システム設定 → プライバシーとセキュリティ を開き、「セキュリティ」までスクロールして、LADE Aquarium の横の このまま開く をクリック。パスワードまたは Touch ID で確認します。

  4. もう一度 LADE Aquarium を開く

    続いて表示されるダイアログで 開く をクリック。次からは普通に開けます。

macOS 13 Ventura / 14 Sonoma

「アプリケーション」で LADE Aquarium を Control キーを押しながらクリックし、開く を選んで、ダイアログでもう一度 開く をクリックします。上のシステム設定の方法でも開けます。

LADE Aquarium が求めることのある許可

  • カレンダー — 次の予定をデスクトップに表示するため。予定は Mac の中でのみ読み取ります。
  • 画面とシステムオーディオの収録 — 音楽の光の輪と彼女の歌う動きが、再生中の音に反応するため。リアルタイムで解析するだけで、録音・保存・送信はしません。
  • アクセシビリティ — 「システムの音量表示を置き換える」をオンにしたときだけ求められ、音量・消音・明るさのキーを受け取るためだけに使います。

どれも任意です。許可しなくても LADE Aquarium は使えます。

アンインストール

LADE Aquarium を終了してゴミ箱に入れ、設定を消すには ~/Library/Application Support/Aquarium フォルダを削除します。
